# Fonts

Subsets of the fonts used on sariyarizwan.com, plus a pixel font for the arcade, embedded in the README images by `scripts/build.mjs`.
GitHub blocks external fonts inside README images, so the images carry their own.

| File | Font | License |
|------|------|---------|
| `instrument-serif.woff2`, `instrument-serif-italic.woff2` | Instrument Serif, Copyright 2022 The Instrument Serif Project Authors | SIL Open Font License 1.1 (`OFL-instrument.txt`) |
| `instrument-sans.woff2` | Instrument Sans, Copyright 2022 The Instrument Sans Project Authors | SIL Open Font License 1.1 (`OFL-instrument.txt`) |
| `jetbrains-mono.woff2` | JetBrains Mono, Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono) | SIL Open Font License 1.1, https://openfontlicense.org |
| `sr-arcade.woff2` | SR Arcade, a renamed subset of Press Start 2P, Copyright 2012 The Press Start 2P Project Authors (cody@zone38.net) | SIL Open Font License 1.1 (`OFL-press-start-2p.txt`) |

Each file is subset to basic Latin plus a few symbols (· – — ’ → ■). The arcade font covers only space through underscore (capitals, digits, punctuation) plus · ▶ ♥ →. "Press Start 2P" is a Reserved Font Name under its license, so the subset carries a different name.
